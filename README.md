# Pre-Entrega – Front-End JS (ESP)
Este proyecto corresponde a la pre-entrega del curso de Front-End JS de Talento Tech.
Se trata de una página e-commerce inspirada en mi propio emprendimiento de amigurumis.
El objetivo fue crear un sitio sencillo, intuitivo y de fácil acceso, utilizando una estética
y colores que transmitan la ternura y el estilo artesanal de los productos.
La página fue desarrollada utilizando HTML y CSS, aplicando los conceptos aprendidos durante el curso.

# Pre-Delivery – Front-End JS (ENG)
This project is part of the pre-delivery assignment for the Front-End JS course at Talento Tech.
It is an e-commerce website inspired by my own amigurumi business. The goal was to create a simple, 
intuitive, and easy-to-navigate website, using an aesthetic and colors that convey the cuteness and handmade 
style of the products.
The website was developed using HTML and CSS, applying the concepts learned throughout the course.
